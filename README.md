# Overview

In this project, my goal was to make a simple text adventure game and handle files and variables in a well organized way. I seperated all of the sections of the game into seperate files and had a seperate file to execute the game. I included the use of variables to alter the outcome of the game.

The game has a list of scenes that you go through, usually in a similar way, but the choices you make will alter a noise variable. If you make dangerous and loud decisions, your noise level will rise, and if you make it to the end of the game with a high noise level, you'll be caught. I included a save/load mechanic that can take your gamestate and write it to a file, then read that file later to put you back where you were.

My intention for this project was to improve my knowledge of how to make a save mechanic, and also to learn how to use C# in unique ways. I've only used C# for limited purposes in the past, and I used a seperate compiler that didn't require .NET, so that was an interesting thing to try and figure out.
